## 🚀 Overview
This repository contains the completely redesigned landing page for **ENIGMA**, our college's student-led coding and tech club. 

The goal of this redesign was to transition the club's digital presence from a raw, text-heavy "cyberpunk" aesthetic into a premium, minimalist "Apple-style" experience. To honor the club's hacker roots, the design system utilizes a **Neon Minimalist** approach—relying on stark black-and-white layouts punctuated by striking Electric Cyan (`#00F0FF`) UI accents and micro-interactions.

## ✨ Key Features
* **Seamless Theme Toggling:** A custom-built, system-aware Dark/Light mode utilizing CSS custom properties for instant, flash-free theme switching.
* **Premium UI/UX:** Features frosted glass navigation (`backdrop-filter`), modern typography, magnetic hover states, and meticulously tuned negative space.
* **High-Performance Motion:** Utilizes vanilla JavaScript and `IntersectionObserver` to trigger buttery-smooth scroll reveals without the overhead of heavy animation libraries.
* **Responsive Architecture:** Fully fluid layouts that scale flawlessly from desktop monitors down to mobile devices.
* **Dynamic Roster:** A clean, grid-based "Team" section showcasing club leadership with integrated social routing.

## 🛠️ Tech Stack
This iteration of the ENIGMA site was built as a single, highly optimized file to be exceptionally fast and lightweight, prioritizing native web APIs over heavy frameworks:
* **HTML5:** Semantic structure and routing.
* **CSS3:** Native styling including CSS Variables, Flexbox, CSS Grid, and custom animations.
* **Vanilla JavaScript:** ES6 logic for DOM manipulation, theme toggling, and intersection observers.
